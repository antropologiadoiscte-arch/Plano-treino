## Gramática por lição

### Lição 1 — 직업 (Profissões)

#### -(이)라고 하다 — chamar-se / dizer-se
- Nome termina em vogal → -라고 하다
- Nome termina em consoante → -이라고 하다
- Usos: apresentar o nome (formal), dizer como se chama uma coisa, citar palavras

Exemplos:
- 저는 안나라고 해요. — Chamo-me Anna.
- 저는 재민이라고 해요. — Chamo-me Jaemin.
- 이건 한국어로 한복이라고 해요. — Isto em coreano chama-se hanbok.

| Forma | Uso |
|---|---|
| 저는 안나예요. | casual, dia a dia |
| 저는 안나라고 해요. | formal, respeitoso |
| 저는 안나라고 합니다. | muito formal |

#### -는 — modificador verbal: "que faz / que está a fazer"
- [raiz do VERBO] + 는 + NOME
- Só verbos (não adjetivos)
- Não muda com 받침
- Raiz em ㄹ → o ㄹ cai (만들다 → 만드는)

Exemplos:
- 먹는 음식 — comida que como
- 공부하는 학생 — estudante que estuda
- 사는 도시 — cidade onde vivo

> 💡 Ordem inversa ao português: 먹는 음식 = "come-que comida" → comida que como.

### Lição 2 — 여가 활동 (Atividades de lazer)

#### -거나 — "ou" entre VERBOS / adjetivos
- raiz + 거나 (sem variação)

Exemplos:
- 주말에 등산하거나 유튜브를 봐요. — Ao fim de semana faço montanhismo ou vejo YouTube.
- 저녁에 요리하거나 한국어를 공부해요. — À noite cozinho ou estudo coreano.

#### -(이)나 — "ou" entre NOMES
- Vogal → -나
- Consoante → -이나

Exemplos:
- 아침에 빵이나 과일을 먹어요. — De manhã como pão ou fruta.
- 커피나 차를 마셔요. — Bebo café ou chá.

> 💡 -거나 liga duas AÇÕES (먹거나 마셔요); -(이)나 liga dois OBJETOS (밥이나 빵).

#### -(으)ㄹ까요? — "Vamos…?" (proposta) ou "Será que…?" (especulação)
- Vogal ou ㄹ → -ㄹ까요?
- Consoante → -을까요?
- ㅂ irregular: 춥다 → 추울까요?

Exemplos:
- 같이 커피 마실까요? — Vamos beber café juntos?
- 내일 비가 올까요? — Será que amanhã chove?

### Lição 3 — 하루 일과 (Rotina diária)

#### 마다 — cada / todos os / sempre que
- NOME + 마다 (sem espaço)
- Substitui -에: nunca 일요일에마다
- Frequência sem exceção

Exemplos:
- 저는 아침마다 차를 마셔요. — Todas as manhãs bebo chá.
- 토요일마다 한국어 수업을 들어요. — Todos os sábados tenho aula de coreano.

> 💡 매일 / 매주 = neutro. 아침마다 / 일요일마다 = enfático, sem exceção.

#### -(으)ㄹ 때 — quando… / no momento em que…
- Vogal → -ㄹ 때 · Consoante → -을 때
- ㄹ 받침 mantém-se: 만들 때, 살 때
- ㄷ irr.: 듣다 → 들을 때
- ㅂ irr.: 돕다 → 도울 때
- ㅅ irr.: 짓다 → 지을 때

Exemplos:
- 시간이 있을 때 등산을 해요. — Quando tenho tempo, faço montanhismo.

> 💡 -(으)ㄹ 때마다 = sempre que · -았/었을 때 = quando (no passado): 어렸을 때.

### Lição 4 — 소개팅 (Encontros)

#### -아/어 보이다 — parece (com adjetivos)
- ㅏ/ㅗ → -아 보이다
- Outras vogais → -어 보이다
- -하다 → -해 보이다

Exemplos:
- 오늘 피곤해 보여요. 괜찮아요? — Hoje pareces cansada. Estás bem?
- 그 원피스가 정말 예뻐 보여요. — Esse vestido parece mesmo bonito.

#### -에다가 — em cima de / para além de / combinar com
- NOME 1 + 에다가 + NOME 2 + verbo
- Pode encurtar: -에다, -에
- Diferente de -하고: implica BASE + ADIÇÃO

Exemplos:
- 원피스에다가 재킷을 입어요. — Visto um vestido e por cima um blazer.
- 밥에다가 김치를 올려서 먹어요. — Ponho kimchi em cima do arroz e como.

| Verbo | Para |
|---|---|
| 입다 | tronco e pernas |
| 신다 | pés |
| 쓰다 | cabeça / rosto |
| 끼다 | anel, luvas |
| 하다 | acessórios |
| 매다 | atar (gravata) |
| 차다 | relógio, cinto |
| 들다 | na mão |
| 메다 | ao ombro |

### Lição 5 — 집 소개 (A minha casa)

#### -기가 좋다 / 편하다 / 힘들다 — é bom / confortável / duro FAZER X
- raiz do verbo + -기가 + adjetivo
- Também: 어렵다, 쉽다

Exemplos:
- 방이 세 개 있어서 가족과 살기가 편해요. — Tem três quartos, por isso é confortável viver em família.
- 우리 집은 지하철이 가까워서 리스본에 가기가 좋아요. — O metro fica perto, por isso é bom para ir a Lisboa.

#### -지 않다 — não (negação longa)
- raiz + 지 않다 (sem variação)
- = 안 + verbo, mais formal/escrito

Exemplos:
- 경치가 좋지 않아요. — A vista não é boa.

> 💡 가지 않아요 = não vou (escolha) · 가지 못해요 = não consigo ir (impedimento).

#### 놓여 있다 / 걸려 있다 — está colocado / está pendurado (estado)
- 놓다 (pôr) → 놓여 있다
- 걸다 (pendurar) → 걸려 있다

Exemplos:
- 책상 위에 책이 놓여 있어요. — Em cima da secretária está um livro.
- 벽에 그림이 걸려 있어요. — Na parede está pendurado um quadro.

### Lição 6 — 주말 활동 (Fim de semana)

#### -(으)면서 — enquanto / ao mesmo tempo (mesmo sujeito)
- Vogal ou ㄹ → -면서
- Consoante → -으면서
- ㄷ irr.: 듣다 → 들으면서, 걷다 → 걸으면서

Exemplos:
- 저는 음악을 들으면서 공부해요. — Estudo enquanto ouço música.
- 커피를 마시면서 책을 읽어요. — Leio um livro enquanto bebo café.

#### -기 전에 — antes de
- raiz + 기 전에 (sem variação)
- Com nomes: NOME + 전에 (수업 전에)

Exemplos:
- 자기 전에 책을 읽어요. — Antes de dormir leio um livro.
- 한국에 가기 전에 한국어를 공부하고 싶어요. — Antes de ir à Coreia quero estudar coreano.

#### -(으)ㄴ 후에 — depois de
- Vogal → -ㄴ 후에 · Consoante → -은 후에
- ㄹ cai: 만들다 → 만든 후에
- Com nomes: NOME + 후에

Exemplos:
- 운동한 후에 샤워를 해요. — Depois de fazer exercício tomo banho.

> 💡 먹기 전에 → 먹으면서 → 먹은 후에 = antes de comer → enquanto come → depois de comer.

### Lição 7 — 스트레스 (Stress e sintomas)

#### -(으)면 — se / quando (condição)
- Vogal ou ㄹ → -면 · Consoante → -으면
- ㅂ irr.: 춥다 → 추우면
- ㄷ irr.: 듣다 → 들으면

Exemplos:
- 스트레스를 받으면 가슴이 답답해요. — Quando apanho stress, sinto um aperto no peito.
- 피곤하면 머리가 아파요. — Quando estou cansada, dói-me a cabeça.
- 날씨가 추우면 어깨가 아파요. — Quando está frio, dói-me o ombro.

> 💡 -(으)면 = condição (받으면 아파요). -(으)면서 = simultâneo (마시면서 봐요).

#### ㅅ 불규칙 — o ㅅ cai antes de vogal
- 붓다 → 부어요 (inchar)
- 낫다 → 나아요 (melhorar)
- 짓다 → 지어요 (construir)
- 젓다 → 저어요 (mexer)
- Antes de consoante fica: 붓지만, 낫고

Exemplos:
- 어제 많이 울어서 눈이 부었어요. — Ontem chorei muito, os olhos ficaram inchados.
- 약을 먹고 아픈 것이 다 나았어요. — Tomei o remédio e as dores passaram.

> 💡 Regulares (ㅅ fica): 웃다 → 웃어요, 씻다 → 씻어요, 벗다 → 벗어요.

#### -지요? / -죠? — não é? / pois não? (confirmação)
- raiz + 지요? (sem variação)
- Na fala: -죠?
- Passado: -았/었지요?

Exemplos:
- 오늘 날씨가 좋지요? — Hoje o tempo está bom, não está?
- 한국어가 어렵지요? — O coreano é difícil, não é?

> 💡 Pronúncia: 바쁘죠 → [바쁘조], 많죠 → [만초].

### Lição 8 — 생활 습관 (Hábitos de vida)

#### -는데 / -(으)ㄴ데 — contexto para o que vem a seguir · "mas" suave
- Verbo, 있다/없다 → -는데
- Adjetivo vogal → -ㄴ데 · consoante → -은데
- 이다 → -인데 · passado → -았/었는데
- ㄹ cai: 살다 → 사는데 · ㅂ: 춥다 → 추운데

Exemplos:
- 머리가 좀 아픈데 혹시 약이 있어요? — Dói-me a cabeça, por acaso tens remédio?
- 요즘 한국어를 공부하는데 아주 재미있어요. — Ando a estudar coreano e é muito giro.
- 커피를 좋아하는데 밤에는 안 마셔요. — Gosto de café, mas à noite não bebo.

> 💡 -아/어서 = causa direta. -는데 = pano de fundo: 아파서 약을 먹어요 vs 아픈데 약 있어요?

#### -아/어 보다 — experimentar / tentar
- raiz + 아/어 보다 (regras do presente)
- Sugerir: -아/어 보세요 (+ 한번)
- 봤어요 = já experimentei · 볼게요 = vou experimentar · 보고 싶어요 = quero experimentar

Exemplos:
- 이 책이 정말 재미있는데 한번 읽어 보세요. — Este livro é mesmo interessante, experimenta ler.
- 잠이 안 오면 가벼운 운동을 해 보세요. — Se não consegues dormir, experimenta exercício leve.
- 한국에 가 보고 싶어요. — Quero ir à Coreia.

#### -지 않는 게 좋다 — é bom NÃO fazer X
- -지 않다 + -는 + 게 좋다 (것이 좋다)
- Afirmativo: 운동하는 게 좋아요

Exemplos:
- 야식을 먹지 않는 게 좋아요. — É bom não comer tarde à noite.
- 컴퓨터를 오래 하지 않는 게 좋아요. — É bom não usar o computador muito tempo.

### Lição 9 — 복습 (Revisão e família)

#### -지 않아요 vs 안 — duas negações, tons diferentes
- -지 않아요: suave, formal, explicativo
- 안 + V: direto, informal
- 있다/없다, 맛있다, 재미있다 só com -지 않아요

Exemplos:
- 아뇨, 안 먹어요. — Não, não como. (direto)
- 저는 지금 다이어트 중이라 먹지 않아요. — Estou de dieta, por isso não como. (explicativo)

> 💡 ✅ 재미있지 않아요 · ❌ 안 재미있어요

#### 못 / -지 못하다 / -(으)ㄹ 수 없다 — não conseguir / não poder
- 못 + V: dia a dia
- -지 못하다: formal / escrito
- -(으)ㄹ 수 없다: formal ou proibição

Exemplos:
- 못 갔어요. — Não consegui ir.
- 가지 못했습니다. — Não consegui ir. (e-mail formal)
- 들어갈 수 없습니다. — Não é possível entrar.

| Verbo | 못 | -지 못해요 | -(으)ㄹ 수 없어요 |
|---|---|---|---|
| 가다 | 못 가요 | 가지 못해요 | 갈 수 없어요 |
| 먹다 | 못 먹어요 | 먹지 못해요 | 먹을 수 없어요 |
| 듣다 | 못 들어요 | 듣지 못해요 | 들을 수 없어요 |

#### ㅅ 불규칙 · tabela — todas as formas
- Antes de vogal (으/아/어) → ㅅ cai
- Antes de consoante (ㄱ/ㅈ/ㄴ) → ㅅ fica

| Verbo | +고 | +(으)면 | +아/어요 |
|---|---|---|---|
| 낫다 | 낫고 | 나으면 | 나아요 |
| 붓다 | 붓고 | 부으면 | 부어요 |
| 짓다 | 짓고 | 지으면 | 지어요 |
| 잇다 | 잇고 | 이으면 | 이어요 |
| 긋다 | 긋고 | 그으면 | 그어요 |
| 젓다 | 젓고 | 저으면 | 저어요 |

## Programa do professor

- **1. 직업**: (이)라고 하다 (apresentar o nome); -는 (modificador verbal)
- **2. 여가 활동**: -거나, (이)나 (ou); -(으)ㄹ까요? (será que…?)
- **3. 하루 일과**: 마다 (cada, todos os); -(으)ㄹ 때 (quando)
- **4. 옷차림**: -기로 하다 (decidir, combinar); 에다가 (juntar a)
- **5. 집**: -기가 좋다 (ser bom para); -지 않다, -지 못하다 (não / não conseguir)
- **6. 장소와 물건**: -(으)면서 (enquanto); -지요(죠) (não é?)
- **7. 스트레스**: -(으)면 (se, quando); ㅅ 불규칙 (irregular em ㅅ)
- **8. 건강한 생활**: -는데, (으)ㄴ데 (contexto, mas); -아/어 보다 (experimentar)

## Exercícios de conjugação (gramática · base → resposta)

- -(이)라고 하다: 민지 → **민지라고 해요** (vogal → -라고 해요)
- -(이)라고 하다: 재민 → **재민이라고 해요** (consoante → -이라고 해요)
- -는 + 음식: 먹다 → **먹는 음식** (raiz + 는)
- -는 + 도시: 살다 → **사는 도시** (ㄹ cai antes de 는)
- -는 + 일: 만들다 → **만드는 일** (ㄹ cai antes de 는)
- -(이)나: 빵 / 과일 → **빵이나 과일** (consoante → 이나)
- -(이)나: 커피 / 차 → **커피나 차** (vogal → 나)
- -(으)ㄹ까요?: 가다 → **갈까요?** (vogal → -ㄹ까요)
- -(으)ㄹ까요?: 먹다 → **먹을까요?** (consoante → -을까요)
- -(으)ㄹ까요?: 춥다 → **추울까요?** (ㅂ → 우)
- -(으)ㄹ까요?: 만들다 → **만들까요?** (ㄹ → -ㄹ까요 (sem 으))
- 마다: 일요일 → **일요일마다** (nunca 일요일에마다)
- -(으)ㄹ 때: 있다 → **있을 때** (consoante → -을 때)
- -(으)ㄹ 때: 자다 → **잘 때** (vogal → -ㄹ 때)
- -(으)ㄹ 때: 만들다 → **만들 때** (ㄹ mantém-se)
- -(으)ㄹ 때: 듣다 → **들을 때** (ㄷ → ㄹ)
- -(으)ㄹ 때: 돕다 → **도울 때** (ㅂ → 우)
- -(으)ㄹ 때: 짓다 → **지을 때** (ㅅ cai)
- -아/어 보여요: 피곤하다 → **피곤해 보여요** (하다 → 해 보여요)
- -아/어 보여요: 좋다 → **좋아 보여요** (ㅗ → 아)
- -아/어 보여요: 작다 → **작아 보여요** (ㅏ → 아)
- -아/어 보여요: 어리다 → **어려 보여요** (ㅣ + 어 → ㅕ)
- -기가 편해요: 살다 → **살기가 편해요** (raiz + 기가)
- -기가 어려워요: 배우다 → **배우기가 어려워요** (raiz + 기가)
- -지 않아요: 가다 → **가지 않아요** (raiz + 지 않아요)
- -지 않아요: 좋다 → **좋지 않아요** (raiz + 지 않아요)
- -지 않아요: 재미있다 → **재미있지 않아요** (só esta forma (nunca 안 재미있어요))
- -(으)면서: 듣다 → **들으면서** (ㄷ → ㄹ + 으면서)
- -(으)면서: 보다 → **보면서** (vogal → 면서)
- -(으)면서: 먹다 → **먹으면서** (consoante → 으면서)
- -(으)면서: 걷다 → **걸으면서** (ㄷ → ㄹ)
- -(으)면서: 살다 → **살면서** (ㄹ → 면서)
- -기 전에: 자다 → **자기 전에** (raiz + 기 전에)
- -기 전에: 먹다 → **먹기 전에** (raiz + 기 전에)
- -(으)ㄴ 후에: 먹다 → **먹은 후에** (consoante → 은 후에)
- -(으)ㄴ 후에: 가다 → **간 후에** (vogal → ㄴ 후에)
- -(으)ㄴ 후에: 만들다 → **만든 후에** (ㄹ cai)
- -(으)ㄴ 후에: 운동하다 → **운동한 후에** (vogal → ㄴ 후에)
- -(으)면: 받다 → **받으면** (consoante → 으면)
- -(으)면: 춥다 → **추우면** (ㅂ → 우)
- -(으)면: 듣다 → **들으면** (ㄷ → ㄹ)
- -(으)면: 피곤하다 → **피곤하면** (vogal → 면)
- -아/어요 (ㅅ): 붓다 → **부어요** (ㅅ cai antes de vogal)
- -았/었어요 (ㅅ): 낫다 → **나았어요** (ㅅ cai)
- -(으)면 (ㅅ): 짓다 → **지으면** (ㅅ cai)
- -(으)ㄹ 거예요 (ㅅ): 젓다 → **저을 거예요** (ㅅ cai)
- -아/어요 (ㅅ?): 웃다 → **웃어요** (웃다 é regular: ㅅ fica)
- -아/어요 (ㅅ?): 씻다 → **씻어요** (씻다 é regular: ㅅ fica)
- -지요?: 좋다 → **좋지요?** (raiz + 지요)
- -지요?: 학생이다 → **학생이지요?** (raiz + 지요)
- -는데: 가다 → **가는데** (verbo → 는데)
- -는데: 있다 → **있는데** (있다/없다 → 는데)
- -는데: 바쁘다 → **바쁜데** (adj. vogal → ㄴ데)
- -는데: 좋다 → **좋은데** (adj. consoante → 은데)
- -는데: 학생이다 → **학생인데** (이다 → 인데)
- -는데: 살다 → **사는데** (ㄹ cai)
- -는데: 춥다 → **추운데** (ㅂ → 우 + ㄴ데)
- -아/어 보세요: 가다 → **가 보세요** (가 + 아 → 가)
- -아/어 보세요: 먹다 → **먹어 보세요** (→ 어 보세요)
- -아/어 보세요: 듣다 → **들어 보세요** (ㄷ → ㄹ)
- -아/어 보세요: 입다 → **입어 보세요** (→ 어 보세요)
- -아/어 보세요: 쓰다 → **써 보세요** (ㅡ cai)
- -지 않는 게 좋아요: 먹다 → **먹지 않는 게 좋아요** (지 않 + 는 + 게 좋아요)
- 못 (3 formas: -지 못해요): 공부하다 → **공부하지 못해요** (raiz + 지 못해요)
- -(으)ㄹ 수 없어요: 듣다 → **들을 수 없어요** (ㄷ → ㄹ)

## Pronúncia

- 음료수 → [음뇨수]: depois de ㅁ/ㅇ, o ㄹ seguinte lê-se [ㄴ] (ㄹ의 비음화).
- 바쁘죠 → [바쁘조], 많죠 → [만초].
